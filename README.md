# 다이렉트볼

한 구씩 찍는 3D 야구 중계 스튜디오입니다. 구단과 선수를 만들고, 구장을 고른 뒤 공마다 구종·회전·타구를 정해 경기를 만듭니다. 만든 중계는 브라우저에서 보고 MP4로 저장할 수 있습니다.

샘플 구단은 가상의 네 팀입니다. 구장은 잠실, 고척, 인천, 수원, 대전, 대구, 사직, 광주, 창원입니다. 담장 거리는 공개된 수치를 쓰고, 폴대 사이 곡선은 그 구장에 맞춰 이었습니다.

## 로컬에서 실행

```bash
npm install
npm run dev
```

개발 서버는 4179 포트입니다. 프로덕션 빌드는 다음입니다.

```bash
npm run build
npm run preview
```

`dist`를 GitHub Pages에 올리면 됩니다. 자산 경로는 상대 경로(`./`)라 저장소 하위 경로에서도 동작합니다. 주소는 해시 라우트라 서버 재작성 없이 페이지가 열립니다.

GitHub에 저장소를 만든 뒤 Settings → Pages에서 Source를 **GitHub Actions**로 두면, `main`에 push할 때마다 `.github/workflows/pages.yml`이 `dist`를 배포합니다. 저장소 이름이 `username.github.io`면 루트에, 아니면 `https://username.github.io/저장소이름/`에 열립니다.

## 만드는 순서

1. 구단에서 이름, 색, 엠블럼을 정합니다.
2. 선수에서 체격을 맞추고, 얼굴 사진을 올리면 이 브라우저 안에서 카드 톤으로 다듬어 머리에 입힙니다. 사진은 서버로 나가지 않습니다.
3. 타자는 타격 루틴, 타격폼, 홈런 세레머니를 키프레임으로 만듭니다. 투수는 투구폼만 만들면 됩니다. 걷기와 주루, 세레머니 외 수비는 기본 동작입니다.
4. 경기에서 상대와 구장, 시작 상황을 고르고 공마다 코스와 구종, 구속, 회전수를 넣습니다. 인플레이는 타구속도, 발사각, 방향, 비거리를 넣으면 궤적을 계산합니다.
5. 중계 화면에서 재생하고, 540p 또는 720p MP4로 저장합니다. 540p는 분당 약 10MB입니다.

ABS 판정은 공의 물리 결과입니다. 비디오 판독은 현장 콜을 보여 준 뒤 최종 선언으로 돌아옵니다. 끝내기에는 덕아웃이 나와 물을 붓고, 맞은 투수는 그 자리에 남습니다. 마지막 이닝을 막은 투수는 점수 차에 따라 세리머니를 합니다.
